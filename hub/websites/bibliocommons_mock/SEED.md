# BiblioCommons desktop pilot

The initial keyword search is Botany. The catalog contains two SFPL print editions and a digital edition by Charles Kovacs. The 2025 edition permits a hold. The historical edition is restricted to use in the library. The local account starts with zero holds. A confirmed request records the selected edition ID, pickup branch ID and active status. Canceling the dialog leaves the account unchanged.

The pilot covers keyword search, an available-title filter, hold placement and the On Hold list. Active holds can be paused and resumed. Checked Out contains two sample loans with predetermined renewal outcomes. One can be renewed once. A request from another patron blocks renewal of the other. Catalog results support three views and a For Later shelf. Fees, events and canceling an existing hold remain outside this pilot. The search page uses the public catalog as a reference. The signed-in flow uses the published help.
