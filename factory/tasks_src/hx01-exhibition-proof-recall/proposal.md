# Tide Marks 展览版画上线

画廊策展人的 Asana 发布卡保留签发版和旧样张。制作人员在 GIMP 的原工作图中选择有权使用的版片，按签发样张上的两个构图框分别精确裁切。交付两个 PNG 和两个保留原始图层的 layered PSD 文档。WordPress.com 更新现有访客文章特色图、署名和媒体说明，Pinterest 发布一条带原文访客链接的 Pin，最后把两个实际地址回填 Asana。
